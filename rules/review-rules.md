# 评审规则（review-rules）

> 来源：secdesign_spec.md §3.10 + §6.4
> 用途：Phase6 security-review 评审安全测试用例的可执行性、可利用性和误报风险。

---

## 4维评审规则

| 维度 | 检查项 | 判定方式 |
|------|--------|---------|
| 可执行性 | 步骤可操作、预期可验证、清理完整 | 规则+LLM裁决 |
| 可利用性 | 威胁是否有可利用的攻击路径 | LLM裁决+攻击模式匹配 |
| 误报风险 | 测试用例是否可能产生误报 | LLM裁决 |
| 攻击链 | 多个中低危威胁是否可串联（scope≥function时） | LLM推理 |

---

## 可执行性检查项

| 检查项 | 说明 | 判定 |
|--------|------|------|
| 步骤可操作 | 每个攻击步骤是否有明确的操作指令（非模糊描述） | 通过/不通过 |
| 预期可验证 | 预期结果是否有可观测的验证点（非主观判断） | 通过/不通过 |
| 清理完整 | 清理步骤是否能恢复测试前状态 | 通过/不通过 |
| 前置条件明确 | 前置条件是否可准备/可满足 | 通过/不通过 |
| 验证方法可行 | 验证方法是否可在目标环境执行 | 通过/不通过 |

### 可执行性阈值

- **可执行性得分 ≥ 70%**：通过（通过检查项数 / 总检查项数 ≥ 0.7）
- **可执行性得分 < 70%**：不达标 → 触发返工

---

## 可利用性检查项

| 检查项 | 说明 | 判定 |
|--------|------|------|
| 攻击路径存在 | 威胁是否有从 Source 到 Sink 的可达路径 | 有/无 |
| 攻击模式匹配 | 是否能映射到 KL-5 已知攻击模式 | 已匹配/未匹配 |
| 前提条件合理 | 攻击前提条件在目标环境是否可满足 | 合理/不合理 |
| 影响可量化 | 攻击影响是否可量化（机密性/完整性/可用性） | 可量化/不可量化 |

> 可利用性为记录维度，不设阈值阻断，但影响攻击链分析判断。

---

## 误报风险检查项

| 检查项 | 说明 | 判定 |
|--------|------|------|
| 预期结果明确 | 预期结果是否区分安全行为与不安全行为 | 明确/模糊 |
| 验证方法可靠 | 验证方法是否可能产生歧义结果 | 可靠/不可靠 |
| 环境依赖说明 | 测试是否依赖特定环境配置（需说明） | 已说明/未说明 |
| 误报场景覆盖 | 是否考虑了正常业务行为可能触发的误报 | 已覆盖/未覆盖 |

> 误报风险为记录维度，不设阈值阻断，但影响测试用例质量评分。

---

## 攻击链验证规则

### 启用条件

- **scope ≥ function 时启用**（function / module / system 均启用）
- scope = interface 时不启用攻击链分析

### 构建规则

1. **识别可串联威胁**：从 threats.json 中筛选多个中低危（S2/S3）威胁
2. **构建攻击链**：将多个威胁按攻击路径串联（如：未授权访问 → 敏感信息泄露 → 命令注入）
3. **生成攻击链测试用例**：为每条攻击链生成端到端测试用例
4. **边界说明**：secdesign 的攻击链是**设计时分析**（纸面推导），不执行实际攻击。执行时验证由渗透测试工具（如 GenCPT）负责，secdesign 的输出作为渗透测试的输入

### 攻击链评估维度

| 维度 | 说明 |
|------|------|
| 可达性 | 攻击链各步骤是否前后衔接可达 |
| 影响放大 | 串联后影响是否大于单点威胁 |
| 检测难度 | 攻击链是否容易被安全设备检测 |

## 返工规则

| 条件 | 动作 | 返工目标Phase | 上限 |
|------|------|--------------|------|
| 可执行性得分 < 70% | 返工 | Phase5（补充/修正测试用例） | 2次（自动返工） |

### 返工流程

1. 识别可执行性不达标的测试用例
2. 将问题清单传递给 Phase5
3. Phase5 修正步骤描述/预期结果/清理步骤
4. 重新执行 Phase6 评审
5. 若仍不达标且未达上限，重复

### 人工返工（interactive模式）

- Gate-2 verdict == "rework" 时触发人工返工
- 人工返工不计入自动返工2次上限
- 人工返工目标 Phase：Phase5
- 人工返工后递增 artifact_version 并重新调度
