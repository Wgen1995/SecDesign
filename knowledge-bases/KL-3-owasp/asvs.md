## 按域分节

### V1 访问控制架构

#### V1.1 访问控制架构文档

- 验证项：确认应用有明确的访问控制架构文档，定义信任边界与授权模型。
- 映射攻击面：A2.2 权限模型变更。
- 检查重点：是否存在 RBAC/ABAC 设计文档、租户隔离方案与权限矩阵。

### V2 认证

#### V2.1 认证架构

- 验证项：确认认证架构满足 ASVS 要求，包括凭据存储、认证协议与失败处理。
- 映射攻击面：A1.2 认证方式变更。
- 检查重点：密码哈希算法、MFA 覆盖、OAuth/SAML 回调白名单。

#### V2.2 通用认证安全

- 验证项：通用认证安全控制，防暴力破解、用户枚举、弱密码。
- 映射攻击面：A1.1 新增用户 / A1.2 认证方式。
- 检查重点：速率限制、锁定策略、错误信息不区分用户名/密码错误。

### V3 会话

#### V3.1 会话管理

- 验证项：会话生成、传递、超时与销毁全生命周期安全。
- 映射攻击面：A1.3 会话管理。
- 检查重点：SessionID 安全随机、Cookie HttpOnly+Secure+SameSite、登录后重置会话、注销销毁。

### V4 访问控制

#### V4.1 通用访问控制

- 验证项：通用访问控制，默认拒绝、最小权限。
- 映射攻击面：A2.1 新增API / A2.2 权限模型。
- 检查重点：每个端点有权限校验、默认无权限、租户数据隔离。

#### V4.2 操作级访问控制

- 验证项：操作级（对象级）访问控制，防 IDOR 与越权。
- 映射攻击面：A2.2 权限模型 / A2.3 资源所有权。
- 检查重点：水平越权测试、垂直越权测试、资源ID不可预测、批量操作所有权校验。

### V5 输入

#### V5.1 输入验证架构

- 验证项：统一的输入验证架构，服务端白名单校验。
- 映射攻击面：A3.1 用户输入处理。
- 检查重点：类型/长度/格式/范围/白名单校验、前后台双重校验。

#### V5.3 输出编码/注入防护

- 验证项：输出编码与注入防护，按上下文编码。
- 映射攻击面：A3.1 用户输入处理。
- 检查重点：HTML/JS/URL/CSS 上下文编码、参数化查询、CSP 头、CSRF 防护。

### V6 加密

#### V6.1 加密架构

- 验证项：加密架构满足分级要求，密钥托管与算法强度。
- 映射攻击面：A4.2 敏感数据存储 / A7.3 通信加密。
- 检查重点：敏感数据分类分级、AES-256-GCM/RSA-2048+、禁止 DES/RC4/MD5/SHA1、KMS 托管。

### V7 日志

#### V7.1 日志架构

- 验证项：日志架构覆盖安全事件，日志不含敏感信息且防篡改。
- 映射攻击面：A4.4 日志审计。
- 检查重点：安全操作审计、日志不含密码/Token、日志权限≤640、保留周期≥180天。

### V8 数据保护

#### V8.1 通用数据保护

- 验证项：通用数据保护，敏感数据最小化与脱敏。
- 映射攻击面：A4.2 敏感数据存储。
- 检查重点：采集最小化、加密存储、日志/界面/导出脱敏、修改场景旧值不可回显。

### V9 通信

#### V9.1 通信安全架构

- 验证项：通信安全架构，全链路 TLS。
- 映射攻击面：A7.3 通信协议与加密。
- 检查重点：全链路 TLS、最低 TLS1.2、禁止弱加密套件、HSTS、双向/服务端证书校验。

### V12 文件

#### V12.1 文件上传

- 验证项：文件上传安全，类型/大小/内容校验。
- 映射攻击面：A3.2 文件上传/下载。
- 检查重点：白名单类型校验、大小限制、Magic Bytes/病毒扫描、上传后重命名、上传目录不可执行。

### V13 REST

#### V13.1 RESTful Web 服务

- 验证项：RESTful Web 服务安全，认证鉴权与输入校验。
- 映射攻击面：A2.1 新增API接口。
- 检查重点：每个端点认证鉴权、参数校验、限流、响应脱敏、越权防护。
