## 完整测试项映射

| WSTG编号 | 测试项 | 映射攻击面 | 测试方法 |
|---------|--------|-----------|---------|
| WSTG-ATHN-01 | 凭证传输测试 | A1.2/A7.3 | 验证凭证仅通过加密通道传输，不出现于 URL、日志或前端缓存中。 |
| WSTG-ATHN-03 | 暴力破解测试 | A1.1/A1.2 | 通过自动化字典/暴力请求测试登录端点的限流、锁定与多因子防御。 |
| WSTG-ATHN-07 | 会话固定测试 | A1.3 | 验证认证成功后会话标识是否轮换，防止攻击者预设 SID 劫持会话。 |
| WSTG-SESS-02 | Cookie属性测试 | A1.3 | 检查 Set-Cookie 是否设置 HttpOnly、Secure、SameSite 属性以防止窃取与 CSRF。 |
| WSTG-SESS-06 | 会话超时测试 | A1.3 | 验证空闲/绝对超时机制是否生效，注销后会话是否立即失效。 |
| WSTG-ATHZ-01 | 目录遍历测试 | A2.1 | 通过路径元字符（../、%2e%2e/）测试能否访问 Web 根目录外文件。 |
| WSTG-ATHZ-02 | 水平越权测试 | A2.3 | 以同级用户访问他人资源 ID，验证是否缺失对象级授权（IDOR）。 |
| WSTG-ATHZ-04 | 垂直越权测试 | A2.2 | 以低权限用户访问高权限功能/接口，验证角色边界是否强制执行。 |
| WSTG-INPV-01 | SQL注入测试 | A2.1/A3.1 | 向输入参数注入 SQL 元字符与布尔/时间盲注载荷，检测数据库异常行为。 |
| WSTG-INPV-02 | 命令注入测试 | A3.1 | 向进入系统调用的输入注入 OS 命令分隔符（;、|、&&）检测命令拼接执行。 |
| WSTG-INPV-05 | XSS测试 | A7.1/A3.1 | 注入脚本载荷验证反射型、存储型与 DOM 型 XSS 及输出编码是否缺失。 |
| WSTG-INPV-11 | 文件上传测试 | A3.2 | 上传可执行/脚本文件与路径穿越文件名，验证类型校验、存储隔离与解析隔离。 |
| WSTG-CONF-05 | 管理界面测试 | A5.2 | 探测管理后台默认路径、默认凭证与访问控制，验证是否最小化暴露。 |
| WSTG-CONF-07 | 限流测试 | A8.3 | 高频重复请求关键端点，验证是否实施速率限制以防止滥用与 DoS。 |
| WSTG-CRYP-01 | TLS配置测试 | A7.3 | 检测 TLS 协议版本、密码套件强度、证书有效性与降级攻击防护。 |
| WSTG-CRYP-03 | 敏感数据传输测试 | A7.3 | 验证敏感字段是否全程加密传输，检查明文回退与混合内容场景。 |
