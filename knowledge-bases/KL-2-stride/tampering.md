# Tampering（篡改）— 攻击者修改数据或代码

> 来源：secdesign_spec.md 附录B
> STRIDE类型：T（Tampering）
> 用途：Phase2 threat-mapper 对适用攻击面套用本模板，识别数据/代码篡改威胁。

## 适用攻击面

A1.2 / A1.3 / A1.4 / A2.1 / A2.4 / A3.1 / A3.2 / A3.3 / A3.4 / A4.1 / A4.2 / A4.4 / A5.1 / A5.3 / A5.4 / A5.5 / A6.1 / A6.2 / A6.3 / A6.4 / A7.1 / A7.3 / A7.4 / A8.1 / A8.2 / A8.4

## 典型威胁

SQL注入、命令注入、XSS、参数篡改、配置篡改、镜像篡改

## 检查方式

注入攻击字符串，篡改请求参数，验证服务端是否过滤；检查文件/镜像/配置完整性签名；验证消息/回调签名是否校验。

---

## A1.2 认证方式变更

- 威胁场景：攻击者篡改认证流程/参数绕过认证。
- 攻击向量：JWT payload篡改配合alg:none、密码哈希算法降级、MFA绕过篡改step参数。
- 映射：CWE-347（签名验证不当）、CWE-287、OWASP A07。

## A1.3 会话管理

- 威胁场景：攻击者篡改会话标识或会话状态。
- 攻击向量：SessionID固定攻击、Cookie属性篡改（去Secure/HttpOnly）、JWT会话state篡改。
- 映射：CWE-384（会话固定）、CWE-565。

## A1.4 凭证存储与传输

- 威胁场景：攻击者篡改凭证或凭证轮换流程。
- 攻击向量：明文凭证文件被篡改注入、凭证传输被中间人篡改、弱哈希凭证被替换。
- 映射：CWE-522、CWE-319、OWASP A02。

## A2.1 新增API接口

- 威胁场景：攻击者篡改API参数/请求体/批量参数。
- 攻击向量：SQL注入篡改查询、参数篡改绕过校验、批量赋值篡改非预期字段。
- 映射：CWE-89、CWE-915（批量赋值）、OWASP A03/API1。

## A2.4 OpenAPI/外部接口

- 威胁场景：攻击者篡改外部接口请求或回调数据。
- 攻击向量：Webhook签名缺失被篡改、外部响应被篡改注入、入站数据未校验被篡改。
- 映射：CWE-345、CWE-20。

## A3.1 用户输入处理

- 威胁场景：攻击者篡改输入注入恶意载荷。
- 攻击向量：SQL/命令/XSS注入篡改后端逻辑、参数污染、路径穿越篡改文件访问。
- 映射：CWE-78 / CWE-79 / CWE-89 / CWE-22、OWASP A03。

## A3.2 文件上传/下载

- 威胁场景：攻击者篡改上传文件内容/类型/名。
- 攻击向量：Content-Type伪造上传Webshell、文件名../穿越篡改路径、图片马绕过检测。
- 映射：CWE-434（不受限制文件上传）、CWE-22。

## A3.3 数据导入/导出

- 威胁场景：攻击者篡改导入数据或导出内容。
- 攻击向量：导入CSV公式注入篡改、导入数据注入SQL、导出文件被篡改注入恶意内容。
- 映射：CWE-1236（CSV公式注入）、CWE-89。

## A3.4 跨系统数据交换

- 威胁场景：攻击者篡改消息内容/顺序。
- 攻击向量：未签名消息被篡改、消息重放/乱序篡改业务状态、MQ消息被篡改注入。
- 映射：CWE-345、CWE-294（重放）。

## A4.1 新增数据库/表

- 威胁场景：攻击者篡改数据库内容或结构。
- 攻击向量：SQL注入篡改/删除数据、未授权DDL篡改表结构、数据库连接被篡改。
- 映射：CWE-89、CWE-284。

## A4.2 敏感数据存储

- 威胁场景：攻击者篡改加密数据/密钥或绕过加密。
- 攻击向量：弱加密算法被篡改明文、密钥泄露后篡改密文、脱敏数据被反向篡改。
- 映射：CWE-327（弱加密）、CWE-326。

## A4.4 日志与审计记录

- 威胁场景：攻击者篡改/删除审计日志掩盖痕迹。
- 攻击向量：日志注入（换行伪造日志条目）、日志文件权限过大被篡改、日志清空。
- 映射：CWE-117（日志注入）、CWE-778、OWASP A09。

## A5.1 新增微服务/组件

- 威胁场景：攻击者篡改微服务配置或服务间通信。
- 攻击向量：配置明文被篡改、服务间未签名通信被篡改、健康检查端点被篡改。
- 映射：CWE-345、CWE-20。

## A5.3 配置文件/环境变量

- 威胁场景：攻击者篡改配置注入恶意值。
- 攻击向量：配置文件权限过大被篡改、环境变量被篡改注入恶意配置、明文密码配置被篡改。
- 映射：CWE-732（权限分配不当）、CWE-15。

## A5.4 证书/密钥管理

- 威胁场景：攻击者篡改证书或替换为伪造证书。
- 攻击向量：弱签名证书被篡改、私钥被替换、证书链被篡改引入恶意CA。
- 映射：CWE-295（证书校验不当）、CWE-327。

## A5.5 第三方依赖引入

- 威胁场景：攻击者篡改依赖包或供应链投毒。
- 攻击向量：依赖混淆篡改包名、CI/CD投毒篡改构建产物、传递依赖被篡改植入后门。
- 映射：CWE-494、OWASP A06/A08。

## A6.1 容器/镜像变更

- 威胁场景：攻击者篡改镜像内容或Dockerfile。
- 攻击向量：未签名镜像被篡改注入后门、Dockerfile被篡改植入恶意层、镜像仓库被篡改。
- 映射：CWE-345、CWE-494。

## A6.2 K8s资源变更

- 威胁场景：攻击者篡改K8s资源清单或运行时资源。
- 攻击向量：篡改Deployment注入恶意命令、篡改RBAC扩大权限、篡改NetworkPolicy开放通信、Secret被篡改。
- 映射：CWE-269、CWE-284。

## A6.3 云资源配置

- 威胁场景：攻击者篡改云资源配置/IAM策略。
- 攻击向量：篡改安全组开放端口、篡改IAM策略扩权、篡改存储桶策略改为公开。
- 映射：CWE-732、CWE-284。

## A6.4 运维命令/脚本

- 威胁场景：攻击者篡改运维脚本植入后门。
- 攻击向量：脚本文件可写被篡改植入恶意命令、Cron被篡改、sudo规则被篡改。
- 映射：CWE-732、CWE-78。

## A7.1 新增界面/Web页面

- 威胁场景：攻击者篡改页面内容/DOM。
- 攻击向量：存储型XSS篡改页面、CSRF篡改用户数据、参数篡改篡改页面行为。
- 映射：CWE-79、CWE-352。

## A7.3 通信协议与加密

- 威胁场景：攻击者篡改通信内容或降级加密。
- 攻击向量：中间人篡改TLS流量、TLS降级攻击篡改版本、弱加密套件被篡改明文。
- 映射：CWE-319（明文传输）、CWE-757（降级攻击）、OWASP A02。

## A7.4 前端安全

- 威胁场景：攻击者篡改前端安全头/CSP。
- 攻击向量：CSP被篡改放宽限制、CORS被篡改为*、X-Frame-Options被篡改。
- 映射：CWE-693（保护机制失效）、CWE-942。

## A8.1 高危操作

- 威胁场景：攻击者篡改高危操作参数或绕过二次认证。
- 攻击向量：ticket篡改/重放、二次授权参数篡改、删除/重置参数篡改。
- 映射：CWE-330、CWE-287、OWASP A04。

## A8.2 业务流程绕过

- 威胁场景：攻击者篡改流程状态/步骤跳过。
- 攻击向量：篡改step参数跳过审批、状态机非法转换、审批结果篡改。
- 映射：CWE-840（业务逻辑错误）、CWE-284、OWASP API6。

## A8.4 竞态条件/幂等性

- 威胁场景：攻击者篡改并发请求制造竞态。
- 攻击向量：TOCTOU篡改检查后使用、幂等Token篡改重放、并发篡改余额。
- 映射：CWE-367（竞态条件）、CWE-294（重放）。
